# Changelog

All notable changes to the Vihaara Yatra International Tours website are documented in this file.

## [1.1] - 2026-11-14

### Added

- Takeoff splash screen (ground-to-sky airplane animation, once per session)
- Brand-first homepage hero featuring **Vihaara Yatra International Tours**
- Package duration dropdowns for **3-10 day** itineraries with indicative pricing
- Packages page duration filter chips (3D-10D)
- About page photography sections
- Destination attraction cards with destination-only images
- Auto-scrolling gallery marquee (unique images, hover to pause)
- Redesigned Travel Guides landing with featured article layout
- Warm forest / sunset / teal / sand theme (moved away from blue-only UI)
- Public GitHub repository documentation suite (README, changelog, attribution, testing report)

### Changed

- Removed long dashes from site copy
- Consolidated package catalogue into duration-based package records
- Homepage gallery preview now uses marquee presentation
- Header announcement bar uses forest-to-teal gradient accents

### Fixed

- Invalid / broken Unsplash image IDs replaced with validated sources
- React hooks ordering on destination and package detail pages
- Navigation breakpoint so mobile menu and desktop links do not conflict

## [1.0.0] - 2026-11-14

### Added

- Initial production static website (React + Vite + TypeScript + Tailwind)
- Core pages: Home, About, Destinations, Packages, Group Tours, Gallery, Guides, Contact, Legal, 404
- WhatsApp integration, enquiry form, SEO metadata, sitemap, robots.txt
- Deployment configs for Vercel, Netlify, and Cloudflare Pages
