# Contributing

Thanks for helping improve the Vihaara Yatra website.

## Workflow

1. Fork or branch from `main`
2. Install dependencies with `npm install`
3. Use `npm run dev` while developing
4. Run `npm run build` before opening a pull request
5. Keep copy accurate: do not invent reviews, awards, prices, or inclusions

## Content edits

Prefer updating data modules under `src/data/` rather than hard-coding marketing copy inside page components.

## Commit style for this project

Release commits should use the version label, for example:

```text
1.1
```

for the v1.1 documentation and feature release.
